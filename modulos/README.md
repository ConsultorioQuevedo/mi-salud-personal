\# 🤖 Quevedo Smart System - Salud y Finanzas

Sistema inteligente de gestión personal con predicción mediante IA.



\## 🚀 Funcionalidades

\- \*\*Gestión Financiera:\*\* Registro y control de gastos/ingresos.

\- \*\*Biomonitor:\*\* Seguimiento de niveles de glucosa.

\- \*\*IA Predictiva:\*\* Proyecciones basadas en Regresión Lineal.

\- \*\*Reportes:\*\* Generación automática de PDF.



\## 🛠️ Instalación

1\. Instalar librerías: `pip install -r requirements.txt`

2\. Ejecutar: `streamlit run main.py`
